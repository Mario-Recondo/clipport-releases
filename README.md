# ClipPort

ClipPort exports your Steam Game Recording clips to plain MP4 files, many at once, in about a second each.

## Download

**[Download the latest ClipPort](https://github.com/Mario-Recondo/clipport-releases/releases/latest)**: under **Assets**, click the file ending in `-setup.exe`. Windows only.

## Installing: the "Windows protected your PC" message

ClipPort's setup file isn't signed yet, so Windows SmartScreen warns you the first time you run each new version. To install:

1. Run the setup file.
2. When the blue "Windows protected your PC" box shows, click **More info**.
3. Click **Run anyway**.
